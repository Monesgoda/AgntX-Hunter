This package includes framework code, agent definitions and a reference library.
Imported references retain their public source attributions and, where available,
upstream paths in `pentest/intelligence_source/playbook_index.json`. The
`legacy/skills-original/` directory contains inert security-methodology
references used by the knowledge reader; it is not a collection of engagement
results or an active legacy agent installation.

material before unrestricted redistribution. Source attributions must be
preserved. Privacy checks and file checksums do not establish licensing rights,
publisher authenticity or freedom from vulnerabilities. Never disable operating
system security controls to run untrusted components.
